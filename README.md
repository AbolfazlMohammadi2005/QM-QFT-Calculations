# 🌀 QM-QFT-Calculations

**QM-QFT-Calculations** is a research-oriented and educational repository dedicated to analytical and numerical calculations in Quantum Mechanics (QM) and Quantum Field Theory (QFT).
The project aims to implement core mathematical and physical structures of quantum theories using **multiple programming languages**, providing a clear and extensible reference for students and researchers.
